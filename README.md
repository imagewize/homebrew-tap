# imagewize/tap

Homebrew tap for Imagewize CLI tools.

```sh
brew install imagewize/tap/wp-ops
```

## Formulas / casks

| Name | Source | Description |
|---|---|---|
| [`wp-ops`](https://github.com/imagewize/wp-ops) | [imagewize/wp-ops](https://github.com/imagewize/wp-ops) | Unified CLI for WordPress operations, Trellis, and Bedrock workflows |

Casks in this tap are published automatically by [goreleaser](https://goreleaser.com/)
on each tagged release of the source project — don't edit files under `Casks/`
by hand, they get overwritten on the next release.
